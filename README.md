# Read & Rip Learn

Football IQ articles from Read & Rip, published at https://readandripqb.github.io/readandrip-learn/

## How publishing works

1. Each new article arrives as a pull request.
2. Read it on GitHub. Ask for changes, or edit it yourself.
3. Click **Merge**. The article is live a minute or two later.

Nothing is published until a pull request is merged.
